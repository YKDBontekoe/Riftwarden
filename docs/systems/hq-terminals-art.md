# HQ + terminal pass (after the fast-pace pass)

> Moved verbatim from the old root `CLAUDE.md` (2026-11). Quoted section names (e.g. "Loot depth", "Run map") refer to other files in this folder (index: [README.md](README.md)). Test counts are the numbers recorded when the work landed, not current totals.

- **Comparison model** (`loot/loadoutScore.ts`): `loadoutScore(items)` -> dps (weaponSummary with equipped stats), ehp ((hull + shield) / (1 - mitigation) at wave 1), mobility and tower indices (100 = stock). `swapImpact(equipped, candidate, replaced)` -> per-headline deltas + verdict (only gains = upgrade, only losses = downgrade, mixed: weighted score >= 3% / <= -3%, else sidegrade). Every list that shows items next to the loadout uses it (storage/arena inventory, market stock, engineering previews of equipped items).
- **InventoryView**: hover previews an item side by side (detail + ComparePanel with the impact banner) without changing the selection; actions only render for the selected item. Search (`matchesQuery`), "upgrades only", "best first" sort, arrow keys + Enter (equip), ignored while typing.
- **Terminal styling** lives at the end of `style.css` ("terminal redesign"): accent per terminal via `--acc`, verdict colours `--up/--down/--side`.
- **HQ surfaces**: `HomeBase` builds deck/wall/ceiling materials from `hqTextures` (ORM + emissive). The arena palette is unchanged. Rooms get accent lighting from `roomStyle` (floor perimeter line, corner columns with slits and colliders except in the command deck, cove strips, cable tray with hangers) and tinted room lights; accent materials are one merged mesh each.
- **Tests**: `tests/loadout-score.test.ts`. Regression after the pass: npm test 342, e2e-m4 39/39, construction G-J 30/30, polish D-E 6/6, progression 18/18, m2 52/54 (C8/C9 fail identically on the pre-pass commit).
- **Hard-surface geometry**: `loftData` turns every rectangular section (n >= 3) into a chamfered octagon (`chamferRatio(n)`: 7-24% of the shorter half-extent) with creased facet columns; along the loft, quads share normals only below a 22 deg bend. Round sections (n < 3, `smoothLatheData`) keep the smooth superellipse path. Kit boxes chamfer 0.035 (was 0.08, which stretched into fat rounded edges when scaled), the enemy soft box is a crisp n=6 chamfered block, HqBuilder boxes default to min(0.035, 12%). Test: `tests/sculpt.test.ts`. Regression: e2e-m3 37/37, polish A-B 13/13.
- **Weathering**: `wearSet(scene, high, rust)` adds rust runs (vertically stretched noise, pitted, lower metal/higher roughness): 1 in the arena, 0.3 in the HQ; every material using the wear albedo (graphite, enamel, enemies) shows it. Outdoor `wallSet` warms its runoff and bleeds rust below rivets; `yardDeckSet` has oil stains, rust stains near joints and canvas-drawn cracks. New palette materials `rust` (`rustSet`: oxide with flaking paint) and `debris` (dark concrete, wear normal only; rubble chunks carry vertex colours, so the arena's `rubbleConcrete` merge group must hold only rubble). Rubble is visual only (no colliders, not pickable) and merged per material (+2 draw calls: debris, rust). HQ: three scrap heaps in reclamation (`HqBuilder.add` is public for them). Tests: `tests/rubble-plan.test.ts`. Regression: e2e-m1 69/70 (the known Z hit-flash compile error; a dedicated HQ + arena + kill load shows no shader errors).
- **Art direction pass** (critique from wide free-camera tours, not close-ups): arena = rift-scarred industrial outpost at storm dusk. Sky: slate zenith, warm dust near the sun, heavier dark clouds, ridges darkened/warmed by sun angle (`rwSky`); `BASE_FOG` [0.3,0.29,0.3], density 0.0042; storm fill 0.26 (cool), sun 1.85 warmer; arena grade contrast 1.22 / exposure 1.08 (`Game`, one line: the constructor is at the 250-line limit). Outdoor palette: concrete [0.4,0.4,0.39] (was cream), panel [0.5,0.52,0.52], white [0.5,0.5,0.48] (clean paint, wear only in ORM), rust amount 0.6; deck oil/rust stains 2-4 m (period 36/40). Skyline quarry rocks are dark cool basalt (`scannedProps`), pushed out x1.35 and lowered. Boss fog mixes to [0.3,0.09,0.08] (polish C2 needs a > 0.1 luminance drop). HQ: graphite deck [0.34,0.36,0.38] with light clear coat, walls [0.6,0.62,0.64], dark ceiling [0.2,0.21,0.23] with one light slot per 2.5 m tile (emissive 2.2), terrazzo [0.3,0.3,0.29], no deck grates, hemi 0.3, contrast 1.16. Tour script pattern: teleport, advance, then set `player.camera.position` + `setTarget` and render (views inside solids show their interior faces: pick viewpoints outside boxes). Regression: npm test 341, polish A-E 21/21, construction G-J 30/30, m1 69/70 (known Z).
- **Second art pass**: viewmodel `ANCHOR` moved down/right (x 0.19, y -0.172, z 0.46, yaw -0.085, pitch 0.015) so the receiver's rear cap leaves the frame; `arctic` shell is worn satin [0.64,0.65,0.63] (was cream), weapon micro texture has grime + stronger scratches (normal 0.45). Partition cheeks use the weathered outdoor `panel`. Build pads (`planPads` in `world/rubblePlan.ts`, rendered by `ArenaFloor.pad`): dark squares with orange corner brackets beside every lane bend, tested clear of lanes/solids/reserved; rubble avoids them. HQ command deck inlay (`HqBuilder.commandInlay`: bronze rings, accent ring and light lines to the three doorways); wall texture seams are faint so the wall-run frames carry the structure. Regression: npm test 342, e2e-m3 37/37.
- **Third pass (weapons, textures, atmosphere)**: weapon micro texture carries machined panel seams (`SEAMS_U`, plus one long seam) with fasteners, so every large shell reads as panels (UVs tile per 0.5 m of weapon); beam shell cheeks use n 3.4 (hard-surface) instead of smooth capsules. Wear texture: weak speckle and brushing (dense dark pits and fine vertical brushing read as cork / wood grain under warm light); outdoor wall runoff streaks ~20 cm. Outdoor `graphite` is painted steel ([0.12,0.135,0.145], metallic 0.22) so the low sun does not turn it tan; new `steel` (blackened, wear only in ORM) on gate tunnel slabs and tunnel dressing. Gate point lights 2.1 (were 3.5). Rift mist + HQ shafts/dust (see layout). Regression: npm test 342, polish 21/21, m1 69/70 (known Z), m3 37/37 (I2 arc check is chance-based: failed once, passed on two reruns).
- **Weapon handling pass**: every shot applies `shotFeel`: pitch kick (def `recoilPitch`) plus a patterned sideways kick (`Player.recoilYaw`, `yawPattern`: ~68% right), a lens punch (`Player.punch`: FOV narrows / roll, layered on top of the smoothed FOV via `appliedPunch` so it never moves the crosshair, decays at 18/s, off with reduced motion), shake for rail/scatter/cycle. Recoil recovers slower while the trigger is held (`recoilRecover` = `recoverFiring`) and fast on release (`recoverIdle`). Firing cancels the sprint pose for 0.35 s. Plasma viewmodel kick ~1.5x; running beams hum (small high-frequency viewmodel shake). Rail charge: `hud.charge` drives a purple arc left of the reticle (mirrors the heat arc), the brackets tighten up to 45% while charging, `chargeReady` ping + pulsing ring at full charge. Masonry impacts get chips + flash like metal; the shoot sound has a low body thump. Tests: `tests/weapon-feel.test.ts`. Regression: npm test 345, m3 37/37, m5 24/24, polish A-C 16/16, m1 69/70 (known Z).
