# Elements (Roadmap step 2, after the combat kit)

> Moved verbatim from the old root `CLAUDE.md` (2026-11). Quoted section names (e.g. "Loot depth", "Run map") refer to other files in this folder (index: [README.md](README.md)). Test counts are the numbers recorded when the work landed, not current totals.

- **Six elements** (`combat/elements.ts` [pure]; `Element` in `combat/events.ts` = `'none' | DamageElement`, where `'none'` is untyped effect damage: no affinity, no elemental power). Kinetic = neutral, no status; thermal = burn; electric = shock chance, x1.5 vs shields (`DamageType` energy); cryo = chill; corrosive = **corrode** (new status in `combat/status.ts`: stacks to 6, 5 s, ticks with the burn clock through `TickHooks.corrode`, +5%/stack damage taken in `vulnerability`, elite plating strips x2 in `EnemyManager.damage`); void = **pierces shields** (`applyDamage(..., pierce)`, the Enforcer frontal shield ignores it; `HitInfo.element`). Elemental (not kinetic/none) damage scales with `elementalPower`.
- **Weapons roll exactly one element**, stored on the item (`WeaponRoll.element`; absent = pre-element weapon = kinetic, no save bump: the field is optional and sanitize keeps only valid ids). `rollElement(family, rarity, rand)` uses its own stream (`seed ^ 0x2c1b3c6d`), so every other roll of a seed is unchanged; kinetic chance 60% common -> 14% exotic; families lean (rail: void, beam: thermal/electric). Starter-grade (`fixedRoll`) kit is kinetic. `weaponDefFor` -> `WeaponDef.element`; `PlayerCombat.damage` deals it with `elementPayload(element, hit, procWeight(hits/s), roll)` (weight 1 at 8 hits/s, 0.25..4, so beams and rails build statuses at a similar rate); Pulse Capacitor splash carries it. PostgreSQL: `005_elements.sql` (column + check), `profileRows` reads it.
- **Affinities** (`affinity(element, {kind, mods}, faction)`, applied in `Director.deal` after elemental power; `Director.faction` = `biomeOf(layout).faction.id`, null on the classic arena = neutral): each faction is weak (x1.35) to two elements and resists (x0.65) two, every element exactly once each (Scrapline weak electric/void, resists kinetic/corrosive; Rime weak thermal/corrosive, resists cryo/electric; Crucible weak cryo/kinetic, resists thermal/void). Overrides multiply: plated frames (bulwark/enforcer/crawler/armored) x1.25 corrosive, frostbound x0.6 cryo, molten x0.6 thermal, shielded x1.15 void; bosses use their own row (Colossus weak corrosive/electric, resists kinetic/cryo; Overseer weak void/kinetic, resists electric/thermal). Clamped 0.4..1.8. `HitResult.aff` / `DamageNumberEvent.el, aff`: numbers are tinted per element with ▲ (weak) / ▼ (resisted).
- **Towers**: ballistic/missile weapons are kinetic and take the core's element (`CoreDef.element`): Thermal Core (thermal), new **Corrosive Core** (corrode 15% of the hit per stack, tech 350 cr / 2 comp / wave 6) and **Void Core** (shield piercing, -5% damage, 450 / 3 / wave 7); arc stays electric and cryo fields cryo (cores still add their burn/corrode/chill). `towerApply` builds every tower hit's payload (missiles store it).
- **Presentation**: elemental weapons glow mostly in the element colour (`elementEnergy` in the viewmodel, preview and bolts via `wfx.setColor`); the model cache key includes the element. HUD weapon card + holster row show an `ElementTag` and a ▲ WEAK / ▼ RESIST hint against the sector faction (`hud.weaponElement/weaponAff`, `holster.element/aff`); item readouts and comparisons show the element; the loading briefing lists the faction's weak/resisted elements (`AffinityRow`, `data-testid=ls-affinity`). `ui/elements.ts` colours come from the table.
- **Co-op**: no protocol change: the server deals damage from the avatar's own weapon def (element included); damage numbers are personal UI events with the new fields.
- **Tests**: `tests/elements.test.ts` (affinity table balance, overrides/clamp/boss rows, roll determinism/distribution/rarity lean, item storage + sanitize + legacy kinetic, payload weights, corrode stacking/shred/ticks/expiry, void pierce, tower elements); e2e-combat G (G1 weapon card element, G2 corrode DoT, G3 void pierces a shield, G4 Rime x1.35/x0.65, G5 briefing affinity row). Regression: npm test 441 (with DB), e2e-combat 33/33, coop protocol 51/51, m5 24/24, m2 50/54 (C8/C9/I4 known; A2/A6/D8/F1 are intermittent random-loot checks; C1/C2 were stale since the TTK pass and now expect `DAMAGE_PACE`), m10 21/24 (C1/C2 sapper fail identically on the pre-elements commit; C3 timing-flaky, passes on reruns).
- **Not done yet**: element reactions for corrosive/void; elemental run upgrades / affixes (M11 conditional affixes); weapon names do not mention the element; tower parts with rolled elements (M11 tower loot); enemy elemental attacks / player resistances; corrode has no persistent body visual (oil puffs only); faction intel on the in-run HUD beyond the weapon hint.
