# Mobile controls + PWA (after the Rift War)

> Moved verbatim from the old root `CLAUDE.md` (2026-11). Quoted section names (e.g. "Loot depth", "Run map") refer to other files in this folder (index: [README.md](README.md)). Test counts are the numbers recorded when the work landed, not current totals.

- **One input path.** The touch overlay (`apps/client/src/touch/TouchControls.tsx`) never calls game methods for actions: it feeds the shared `Input` (`simulateKey` / `simulateMouse` with the default codes the game listens for, `look(dx, dy)` in mouse-equivalent px, `setStick(x, z, sprint)`), so arena, HQ, co-op replicas and the keyboard all share one code path. `Player.update` reads the analog stick (`stickX/stickZ` replace WASD while deflected; run speed x deflection; `stickSprint` = sprint). Only pause goes direct (`pauseWorld` = what Escape does).
- **Touch mode** (`Input.touch`): input counts as captured without pointer lock; `requestLock` calls `onEngage` (fullscreen + `screen.orientation.lock('landscape')`, inside the gesture; iPhone Safari has neither, the installed app is fullscreen anyway). Setting `touchControls` auto/on/off; auto turns on for a coarse pointer with touch points and then follows the last pointer kind (a tap turns it on, a mouse click turns it off and pauses, since there is no pointer lock yet). Taps fire compatibility mouse events: `Input` ignores mouse events for 900 ms after a touchstart. `?touch` forces it; `?test` counts engage requests (`window.__touch.immersiveStats`) instead of entering fullscreen.
- **Layout** (landscape): floating stick anywhere in the left 42% (`TOUCH.stickZone`), drag anywhere else to look, FIRE (drag it to aim while firing; PLACE in build mode), JUMP, DASH, SLIDE (slide / pound), HOOK (grapple = middle mouse), SWAP, ability I/II (CANCEL in build mode), ULT (combat only); top row WAVE (prep), BUILD, TOWERS (prep), SLOW, MAP (when `canReturnHome`), CARGO, pause; context row PICK UP / USE, tower LEVEL / REPAIR / hold RECYCLE (fill shows progress), build part cycling. HQ: stick, look, JUMP, DASH, USE (prompt), pause bottom left. Sizes follow `vh` (`--b`), safe-area insets respected. Touch-mode HUD (`touch.css`): zoom 0.66 below 600 px height, key chips hidden, weapon card moved above the drone panel (zoom scales offsets, so offsets are divided by it), node chip lower. Menus/terminals are touch-native (buttons, `overflow: auto` scrolls with a finger); bigger tap targets under `html[data-touch]`. The overlay re-renders with the HUD snapshot (`useHud((s) => s)`: a selector that builds an object would loop `useSyncExternalStore`).
- **Settings**: `touchControls`, `touchLook` (0.3..3, multiplied with the mouse sensitivity; `TOUCH.lookScale` 1.6), `touchOpacity` (no version bump, sanitize fills them). First start on a touch device uses `mobileDefaults()` (performance preset, render scale 0.7); stored settings always win. Portrait shows `RotateHint` (fullscreen button, dismissable).
- **PWA**: `public/manifest.webmanifest` (fullscreen, landscape, maskable icon), iOS meta + apple-touch-icon in `index.html` (`viewport-fit=cover`, no zoom). The service worker (`sw-plugin.ts`) caches the icons + manifest with the shell; the first install activates at once, **updates wait** until the page posts `{type:'skip-waiting'}` (`UpdateToast` RELOAD; it warns that reloading ends a running operation); `controllerchange` reloads; the page checks for updates every 30 min. `beforeinstallprompt` is captured in the shell (`pwa.ts`, before the game chunk) for INSTALL APP (main menu + Settings > Controls); iOS gets Share > Add to Home Screen instructions.
- **Tests**: `tests/touch.test.ts` (14: stick dead zone/drive/clamp/sprint/finite, knob, look scaling, mode rules, portrait, settings sanitize + mobile defaults, manifest + icons exist, index.html meta, generated SW waits for skip-waiting and parses); `node scripts/e2e-mobile.cjs` 34/34 (needs `pnpm dev`); `npm run build && node scripts/e2e-pwa.cjs` 7/7 (Chromium installability, offline start, update flow). Regression: npm test 531, lint unchanged (6 warnings), build OK.
- **Not done yet** (owner: "not now"): layout editor, haptics, gamepad. Also: gyro aim, aim assist for touch, touch-specific hint texts (HUD hints still name keys), co-op lobby and run map were not walked on a phone, no real-device check (iOS Safari fullscreen/orientation, Android install banner, real-GPU frame rate on phones).

- **Vibration** (`touch/haptics.ts`, Settings > Controls > Vibration, default on): a 12-60 ms pulse per hit while
  the arena touch controls show, scaled by severity, lighter on the shield, at most one per 140 ms; only where
  `navigator.vibrate` exists. Tests: `tests/haptics.test.ts`.
